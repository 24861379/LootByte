# LootByte
LootByte es una aplicación móvil de comercio electrónico orientada a la venta de periféricos gamer. Permite a los usuarios explorar el catálogo de productos, registrarse, iniciar sesión, gestionar su perfil y realizar procesos de compra. Además, cuenta con un módulo administrativo para la gestión de productos, usuarios y pedidos.
